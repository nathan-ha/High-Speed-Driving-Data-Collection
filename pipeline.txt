
- Parse PEMS data (station hourly), store data into dictionary

- Get speed limit at all stations using open street maps

- Create speed bins
  - Calculate VMT by taking (flow) * (station length)
  - Sum VMT across all 1 hour intervals per station
  - Speed bin is calculated using average speed (given by PEMS)
  - VMT is added to bin

- Find VMT above threshold (65, 70, 75, 80, 85, 90 mph)
  - if average speed is above threshold, add VMT to a counter
  - calculate proportion of VMT above that threhold

- Find VMT above speed limit
  - Compare station average speed to the speed limit at that station
  - If average speed is higher, add VMT to counter
